# Derik1.2 Data Archive

This directory is reserved for data and analysis files related to Derik1.2.

## Structure

- `CSV/` — exported CSV datasets
- `Logs/` — diagnostic and execution logs
- `Reports/` — generated reports
- `Analysis/` — statistical analysis and scenario results

Large files can be tracked with Git LFS when LFS is configured for the repository. Keep source code and existing files in the Derik branch unchanged.
